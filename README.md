# QuickCalc_JustForWork

公司内部使用的工作计算器，包含重量、密度、随机数和工时工资四个工具。纯前端，无需安装依赖，计算在浏览器本地完成。

## 如何使用

下载整个项目，用浏览器打开 `index.html` 即可。请保留旁边的 `assets` 文件夹。

如果只想发一个文件给同事，可以生成单文件版本：

```sh
node scripts/build.cjs
```

生成的 `dist/QuickCalc.html` 包含全部样式和功能，可以单独发送、离线打开。只有测试和打包需要 Node.js，日常使用不需要。

## 功能

| 工具 | 用途 |
| --- | --- |
| 计算重量 | 根据圆柱或圆管的外径、内径、长度和密度计算重量；内径为 0 表示实心。 |
| 计算密度 | 根据尺寸和重量计算密度。尺寸单位为 mm，重量为 g，密度为 g/cm³。 |
| 随机数 | 生成整数或浮点数，支持正负偏移、不重复及小数位数；可按行或列复制到 Excel。 |
| 工时工资 | 根据上下班时间和时薪自动计算工资，手动选择午餐、晚餐和交通费补贴。 |

### 工时工资

时薪默认 **15 元/小时**，可以修改。补贴开关默认关闭，由使用者手动判断，不按饭点自动选择。

| 开关 | 工时处理 | 额外补贴 |
| --- | --- | ---: |
| 加午餐 | 扣 30 分钟 | 10 元 |
| 加晚餐 | 不扣时间 | 15 元 |
| 补交通费 | 不扣时间 | 10 元 |

补贴单独列在工资后面。例如：08:00–19:00，时薪 15 元，三项全选，显示 **¥157.50 + ¥35.00 补贴**。

- **按 10 分钟取整**：开启后，将计薪工时四舍五入到最接近的 10 分钟，恰好 5 分钟向上取整；加午餐时先扣 30 分钟，再取整。关闭时精确到分钟。
- **工资金额**：计薪分钟 ÷ 60 × 时薪，最终金额四舍五入到分。
- **复制明细**：复制时保留工资、午餐、晚餐和交通费明细。

### 时间怎么填

按 24 小时制填写：下午 1 点是 **13:00**，晚上 8 点是 **20:00**。

| 上班 → 下班 | 上班时长，未扣午餐 |
| --- | --- |
| 08:00 → 13:00 | 5 小时 |
| 11:40 → 13:00 | 1 小时 20 分钟 |
| 20:00 → 04:00 | 自动按次日下班，8 小时 |

上午上班、下班时间却更早时，会提醒核对是否误填了下午时间。例如 `08:00 → 01:00` 提醒是否应填 `13:00`；提醒不会自动修改时间或阻止计算。

目前按单次、不足 24 小时的班次计算，时间相同按 0 分钟处理，不支持多天连续工时。

### 随机数与保存

- 随机数单次最多生成 10000 个；范围容纳不了指定数量的不重复结果时会提示调整。
- 行输出用 Tab 分隔，列输出用换行分隔，可直接粘贴到 Excel。
- 输入和开关保存在当前浏览器，刷新后可恢复；生成的随机数结果不保存。
- 浏览器禁止本地存储时仍可计算，只是不保存输入。项目不上传这些输入数据。

## 项目结构

```text
index.html                 页面结构
assets/
  styles.css               页面样式
  core.js                  计算逻辑
  state.js                 输入保存与恢复
  app.js                   页面交互与结果显示
scripts/build.cjs          打包为单个 HTML
tests/                     自动测试与旧版对照数据
```

修改功能时，计算规则放在 `core.js`，页面交互放在 `app.js`；样式和页面结构分别维护。

## 开发与验证

不需要安装第三方依赖：

```sh
# 运行全部测试
node --test tests/*.test.cjs

# 生成单文件版
node scripts/build.cjs
```

目前包含 42 项自动测试，覆盖工资、补贴、取整、跨夜、误填提醒、随机数边界和存储异常。

整理代码前已保存对照结果：128 组工资逐项一致，12 组尺寸的体积、重量和密度与 GitHub 原版一致，8 组随机数设置通过范围、数量、唯一性和格式检查。基准数据保存在 `tests/fixtures/calculation-baseline.json`。

唯一随机数的抽样方式经过优化，因此具体随机值可能与旧版不同，不重复和范围要求保持一致。
